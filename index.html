数据说明

了解面板的数据来源、计算口径与本地隐私边界。

01

会话数据

直接读取本机 Codex 会话日志中的 token_usage_record，不读取或展示聊天正文。 默认监控环境变量指向的当前会话，若不存在则选择最近更新的会话。

02

账户余额

本地 Node 服务读取 DEEPSEEK_API_KEY 或 Codex 配置中的 DeepSeek 凭证， 再请求官方 /user/balance 接口。浏览器只会收到余额，不会收到密钥。

03

上下文占用

取最近一次模型调用的输入 Token 加输出 Token，再除以当前模型上下文窗口。 当前 DeepSeek 模型窗口为 1,000,000 tokens。

04

缓存命中率

缓存命中率 = 累计缓存命中输入 Token ÷ 累计输入 Token。 缓存节省金额按“全部输入均未命中”与“实际命中/未命中拆分”的差额计算。

本地优先，数据不离开你的电脑

页面与服务都只监听 127.0.0.1。请求日志仅包含接口路径，不记录 API Key 或聊天内容。若部署到其他设备，请先补充身份验证与 HTTPS 防护。

仅本机访问 无第三方埋点 不保存正文

接入你自己的应用

面板默认读取 Codex 会话。若要把其他应用的用量接入监控，可在每次 DeepSeek 调用后保留 usage 字段，并按相同口径累计输入、缓存命中、输出与上下文 Token。 

usage: {
  input_tokens,
  cached_input_tokens,
  output_tokens,
  reasoning_output_tokens
}
